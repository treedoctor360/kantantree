# かんたん樹木登録（kantantree）

作業中に「この木、番号を振っておきたい」と思った瞬間に、3タップで1本を登録するための道具。
点検・診断はしない。位置・樹種・番号・写真だけを残す。

仕様は [CLAUDE.md](./CLAUDE.md) にまとめてある。

## 公開先

**https://treedoctor360.github.io/kantantree/**

`main` に push すると GitHub Actions が自動でビルドして公開する。

### スマホで使い始める

1. 上のURLをスマホのブラウザで開く
2. **ホーム画面に追加する**（毎回URLを開かなくて済む）
   - iPhone (Safari): 共有ボタン → 「ホーム画面に追加」
   - Android (Chrome): 右上の︙ → 「ホーム画面に追加」
3. 最初に **設定タブ → ＋公園を追加** で公園を1つ登録する（これがないと樹木を登録できない）
   - 公園コードは `P001` が自動で入る。そのままでよい
   - その公園にいるなら「📍 現在地を入れる」で代表座標も入れておくと、地図タブがその公園から開く
   - 公園がたくさんあるなら **📤 CSVから取り込む** で一括登録できる（下記）
4. あとは **登録タブ** で「📍現在地 → 📷撮影 → 登録」

初回に位置情報とカメラの許可を聞かれるので許可する。
（`https://` でないとブラウザが位置情報を使わせてくれないため、上のURLから開くこと）

> **データはこの端末の中だけに保存される。** クラウドには送らない。
> 機種変更や端末の初期化でデータは消えるので、ときどき
> 設定タブ → **JSON（フル・写真込み）** を書き出しておくこと。
> 設定タブに「最終バックアップから◯日」が出る。

## ターミナル操作

```bash
# 1. 依存を入れる（最初の1回だけ）
npm install

# 2. 開発サーバを起動する
npm run dev
#    → http://localhost:5173/kantantree/ が開く

# 3. 採番などのテストを走らせる
npm test

# 4. 本番用にビルドする（dist/ ができる）
npm run build

# 5. ビルドしたものを手元で確認する
npm run preview
```

スマホの実機で試すときは、パソコンと同じWi-Fiにつないで次のように起動する。

```bash
npm run dev -- --host
#    → 表示された http://192.168.x.x:5173/kantantree/ をスマホで開く
```

> 位置情報（GPS）と カメラ は、`https://` か `localhost` でないとブラウザが使わせてくれない。
> 実機でGPSまで試したいときは、GitHub Pages に上げたものを開くのが早い。

## 公園をCSVから取り込む

設定タブの **📤 CSVから取り込む**。樹木台帳メモ（parktreenote）の公園マスタと同じ形式なので、
同じCSVを両方のアプリに読ませられる。

| 列 | 扱い |
|---|---|
| `児童遊園地名` / `公園名` / `タイトル` のいずれか | **必須**。公園名として読む |
| `ID` | あれば `pid` として保持（プリザンター等のID） |
| `緯度` / `経度`（`lat` / `lng` も可） | あれば代表座標に入れる |

- 文字コードは UTF-8 でも Shift_JIS でもよい（自動判定）
- 公園コードは `P001` から続きを自動で付ける
- すでに登録済みの公園は飛ばす。表記ゆれ（`皇子が丘公園` と `皇子が丘 公園`）も
  同じ公園とみなす
- 並び順はCSVの行順

## データの持ち方

- 保存先は端末内の IndexedDB。クラウド同期はしない。
- 端末を替えるときは、設定タブの **JSON（フル・写真込み）** を書き出して、
  新しい端末で **JSONを読み込む** を実行する。
- 読み込みは「追記マージ」。同じ `id` は更新日時の新しい方を採用し、知らない `id` は追加する。
  実行前に「追加◯件 / 更新◯件」を確認ダイアログで出す。
- バックアップを取らないまま端末を初期化するとデータは戻らない。設定タブに
  「最終バックアップから◯日」を出しているので、ときどき書き出しておくこと。
